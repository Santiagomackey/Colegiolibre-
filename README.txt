ColegioLibre — corrección de altura y scroll de Mensajes

1. Descomprimí el ZIP.
2. Copiá apply_fix.py y mensajes-layout-fix.css a la raíz del proyecto ColegioLibre.
3. Desde esa carpeta, ejecutá: python apply_fix.py
4. Subí los archivos modificados a GitHub y desplegá en Vercel.
5. Verificá escritorio, tablet y celular.

El script actualiza mensajes.html y mobile-app/www/mensajes.html cuando existen.
No modifica los mensajes ni los datos de Supabase.

Nota: el arreglo se basa en los archivos de la rama main de GitHub consultados el 11/11/2026.
