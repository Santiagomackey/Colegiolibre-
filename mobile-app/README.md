# ColegioLibre Android 1.0.26

Leé ../LEEME-ARREGLOS.md para compilar desde terminal, desplegar y verificar esta versión.

Una única configuración: capacitor.config.json. La app carga la web de producción mediante HTTPS y requiere conexión. No se incluye un APK compilado nuevo.

Esta versión agrega SystemAppearance (Android): barra del sistema y gestos blancas en modo claro y oscuras en modo oscuro, con iconos legibles. También elimina fondos azules forzados de los controles móviles. Desplegá los archivos web y recompilá/reinstalá el APK para incluir el nuevo plugin nativo. No se ha compilado ni verificado en un teléfono en este entorno.

Para configurar Apple y los avisos Android, leé ../docs/APPLE_AND_PHONE_NOTIFICATIONS.md. Esta entrega no contiene un APK compilado.
